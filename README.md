# DIY-CNC

This design is my take on the common gantry CNC mill.

Specs - 

- 290 x 315 x 88 mm working area
- 800W water-cooled spindle
- SFU1204 ball screws for XYZ axis
- Nema 17 open loop stepper

Software - 
GRBL
